## Toolchain facts worth not rediscovering

- **`py -3.11` has no pyarrow; the system `python` (3.14.7) does.** So the intraday harness, the
  trader's `--replay`, `sweep_o1.py` and anything reading `data/**/*.parquet` must run on
  `python`, not `py -3.11`. `py -3.11` is for LEAN algorithms and `compare_orders.py`.
- **`intraday_trader.py --replay` does not read `live/intraday_config.json`** - it takes strategy
  defaults unless `--params` is passed, and `--equity-frac` defaults to 1.0. A replay meant to
  reproduce the deployed book must be run as
  `python scripts/intraday_trader.py --replay <date> --equity-frac 0.5 --params "$(python -c
  "import json;print(json.dumps(json.load(open('live/intraday_config.json'))['params']))")"`.
  Run without those it reports 217 trades / -9,914 instead of the deployed 34 / -2,280, which
  looks like a regression and is not one. `intraday_launch.py` is what passes the config live.
- `live/alerts.json` **does not exist on this machine right now**, so both `notify()` paths were
  silent no-ops. P-1's fix (below) makes that visible instead of invisible.
